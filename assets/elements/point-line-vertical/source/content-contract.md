# 点标记竖线（测试） Content Contract

批准来源：2026-10-20，用户选择“批准两份内容合同”，随后明确“Implement the plan.”。本文件记录该具体批准，不授权其他新内容。

- ID：point-line-vertical；元素、算法、内容包版本均为 1；ABI 2 / V2。
- 输入只允许一条点轨道内一个分类，外部包不保存真实绑定；空分类透明，未绑定阻止导出。
- 竖线贯穿高度，随机横向位置；中心位于 1%–99%，相邻点位置差至少 5%。每点独立，可短暂叠加。
- 默认颜色 #ffffff、线宽为短边 0.003；线宽范围 0.0005–0.02。
- 提前 0.04 秒平滑渐显，点时刻最亮，停留 0.06 秒，再用 0.10 秒平滑渐隐；渐显/渐隐范围 0.01–0.5 秒，停留范围 0–1 秒。
- 默认全曲手动时段，只触发该时段内的点；歌曲/元素边界裁剪。点集合 includeEnd 支持曲尾点的提前渐显。
- seed、方向、事件 ID 与时间顺序决定位置；按修订分页建立索引，每帧查询活动点，seek/循环/导出一致。
- 每批至多 65,536 顶点，后续批次复制前一批再画新线，不丢事件。不创建 Canvas/Renderer/RAF/音频链。
- 验证覆盖声明/单分类、空输入、包络边界、相邻间距、分页/分批、确定性、Chrome/Edge GPU 及短离线 WebM；结果由实际交付报告，不在合同中预写通过。
